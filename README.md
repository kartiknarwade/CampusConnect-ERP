# CampusConnect ERP

A modern Campus Management System built using:

- React.js
- Spring Boot
- Spring Security
- Hibernate/JPA
- MySQL

## Features

- Authentication & Authorization
- Student Management
- Teacher Management
- Attendance Management
- Marks Management
- Fee Management
- Notice Board
- Timetable Management

## Tech Stack

### Frontend
- React.js
- Bootstrap 5
- Axios
- React Router

### Backend
- Spring Boot
- Spring Security
- Hibernate/JPA

### Database
- MySQL
